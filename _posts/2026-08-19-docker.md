Dans ce court article nous allons installer docker

Sur notre serveur Debian BlackWall dans un premier temps une petite maj

```
apt update && apt upgrade
```

un petit prérequis avant (sécurisation de la connexion HTTPS)

```
apt install -y curl gnupg ca-certificates
```
Il peut arriver que lsb_release -cs soit absent de votre serveur au cas où :

```
apt install -y curl gnupg ca-certificates lsb-release
```


Clé GPG officielle Docker
Cela permet de vérifier que les paquets que l'on télécharge depuis le dépôt Docker sont authentiques

```
install -m 0755 -d /etc/apt/keyrings
curl -fsSL https://download.docker.com/linux/debian/gpg | gpg --dearmor -o /etc/apt/keyrings/docker.gpg
chmod a+r /etc/apt/keyrings/docker.gpg
```

Ajout du dépôt officiel Docker

```
echo "deb [arch=$(dpkg --print-architecture) signed-by=/etc/apt/keyrings/docker.gpg] https://download.docker.com/linux/debian $(lsb_release -cs) stable" | tee /etc/apt/sources.list.d/docker.list > /dev/null
```

Et enfin une fois ces étapes faites 

```
apt update && apt install -y docker-ce docker-ce-cli containerd.io docker-buildx-plugin docker-compose-plugin
```

Ajouter votre utilisateur au groupe docker 

```
usermod -aG docker <votre user>
```

/!\ Attention faire partie du groupe docker équivaut à un accès root sur le serveur, faire ça pour le homelab c'est ok mais **PAS EN PROD** gardez **`sudo docker`** ou le mode rootless

Démarrage auto

```
systemctl enable docker && systemctl start docker
```

Vérification de l'installation

```
docker run hello-world
```

Configuration du daemon

```
cat > /etc/docker/daemon.json << 'EOF'
{
  "log-driver": "json-file",
  "log-opts": {
    "max-size": "10m",
    "max-file": "3"
  },
  "storage-driver": "overlay2",
  "live-restore": true
}
EOF
```

```
systemctl restart docker
```

- **`log-driver json-file`** + limites -> Cela évite de saturer les disques avec des logs
- **`overlay2`** -> driver de stockage recommandé par défaut pour les systèmes de fichiers modernes 
- **`live-restore`** -> les conteneurs continuent de tourner si le daemon redémarre (non compatible swarm)
